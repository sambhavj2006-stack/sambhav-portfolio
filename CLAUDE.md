# Sambhav Portfolio

## Project Vision

Build a premium portfolio website that feels like the intersection of Apple, Vercel, Linear, Stripe and OpenAI.

The website should communicate:
- Leadership
- Product thinking
- Consulting excellence
- Technical curiosity
- Modern design

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- App Router

## Engineering Rules

- Build reusable components.
- Never create duplicated code.
- Keep components under ~200 lines where practical.
- Explain architectural decisions before large changes.
- Prefer composition over repetition.
- Keep accessibility and performance in mind.

## Design Language

- Minimal
- Elegant
- Premium
- Motion-first
- Plenty of whitespace
- Smooth animations
- No generic templates

## Working Style

When implementing features:
1. Explain the plan.
2. Implement one feature at a time.
3. Wait for approval before large refactors.
